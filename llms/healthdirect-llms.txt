# Healthdirect Australia — National Health Services Directory (NHSD)

> Healthdirect Australia is a national, government-owned, not-for-profit operator of core Australian digital-health infrastructure. Its developer surface is the National Health Services Directory (NHSD) Integration Hub, exposing standards-based HL7 FHIR R4 APIs over an authoritative directory of 400,000+ health service and practitioner records, aligned to the HL7 AU Provider Directory (AU-PD) guide with SNOMED CT-AU terminology and G-NAF geocoded addresses. Integration is gated behind formal onboarding; APIs are secured with OAuth 2.0 client-credentials plus an x-api-key header. Home market: Australia.

## APIs
- [NHSD FHIR API](https://about.healthdirect.gov.au/what-we-do/portfolio/nhsd/integration-hub/documentation): Real-time, read-only FHIR API over Organization, HealthcareService, PractitionerRole, and Practitioner (AU-PD). Base: https://api.fhir.nhsd.healthdirect.org.au/v4
- [NHSD FHIR Bulk Data Export](https://build.fhir.nhsd.healthdirect.org.au/v4/bulkexports.html): Read-only FHIR bulk data export for full-directory retrieval.
- [NHSD FHIR Ingestion & Data Acquisition Hub](https://build.fhir.nhsd.healthdirect.org.au/ingestion/index.html): Inbound FHIR interface for approved data-contributing sources.
- [NHSD Provider Appointments API](https://about.healthdirect.gov.au/what-we-do/portfolio/nhsd/integration-hub/documentation): Real-time appointment availability from certified booking platforms.
- [NHSD Search Widget](https://media.healthdirect.org.au/publications/NHSD_widget-implementation-guide.pdf): Embeddable directory search component.

## Auth
- OAuth 2.0 client_credentials (token endpoint /iam/oauth/token) returning `accessToken`, sent as `Authorization: Bearer`, plus a static `x-api-key` header on every request. No SMART-on-FHIR scopes. Credentials issued via NHSD onboarding.
